Question 1 Biological Neuron
Which of the following components of a biological neuron is primarily responsible for processing information received from other neurons in the brain?
A Dendrites
B Soma  [CORRECT ANSWER]
C Axon  [INCORRECTLY MARKED IN PROMPT]
D Synapses
Deep Technical Breakdown

A biological neuron has four primary structural regions, each corresponding directly to computational blocks in artificial intelligence:

  • Dendrites (Input Receivers): Branch-like projections that receive chemical messages (neurotransmitters) across synaptic clefts and convert them into graded post-synaptic electrical potentials (EPSPs and IPSPs).
  • Soma / Cell Body (Central Processing Unit): The metabolic center containing the nucleus. Critically, the soma performs spatial and temporal summation (algebraic aggregation and integration) of all incoming excitatory and inhibitory graded potentials. The soma and its axon hillock decide whether the net integrated membrane potential crosses the excitation threshold. Hence, it is the primary site of information processing.
  • Axon (Transmission Line): A long, slender cylindrical projection (often myelinated) responsible for conducting / propagating the generated all-or-none action potential away from the cell body toward downstream cells. It does not process; it transmits.
  • Synapses (Junctions / Weights): The structural interfaces between neurons where neurochemical signal transmission occurs, providing adjustable transmission efficacy (analogous to synaptic weights wi).

Conclusion: The biological component responsible for processing (aggregating and deciding) is the Soma (Option B).

Question 3 / 10 McCulloch-Pitts Neuron
In question 2, Which of the specifications listed in the table is an inhibitory input to the MP neuron?
A Price
B 5G support
C not made in India  [CORRECT ANSWER]
D None of those
Deep Technical Breakdown

In the classic McCulloch-Pitts (MP) neuron model introduced by Warren McCulloch and Walter Pitts (1943):

  • Inputs are strictly binary: xi ∈ {0, 1}.
  • Inputs are divided into two disjoint sets: excitatory inputs (which contribute +1 toward reaching an activation threshold θ) and inhibitory inputs.
  • Inhibitory inputs possess absolute veto power: if even a single inhibitory input is active (equal to 1), the neuron is unconditionally silenced (output y = 0), regardless of how high the sum of excitatory inputs is!
y = 0    if any inhibitory input equals 1
y = 1    if all inhibitory inputs equal 0 AND Σ xi ≥ θ

In the standard phone-purchase decision problem (introduced in NPTEL Deep Learning):

  • Features like 5G support, high RAM, and good camera are desirable features that add positive evidence towards buying (excitatory).
  • The feature "not made in India" serves as an absolute deal-breaker (veto): if a phone is not made in India (value = 1), the buyer will never purchase it under any condition (output forced to 0).

Thus, not made in India is the inhibitory input (Option C).

Question 4 / 10 Boolean Functions & Inhibition
Consider the statement: "All Boolean functions cannot be implemented using only excitatory inputs (i.e., without inhibitory inputs)." Which of the following is correct?
A True — it holds for some Boolean functions regardless of linear separability.  [CORRECT ANSWER]
B True — it holds for non-linearly separable Boolean functions.
C False — every Boolean function can be implemented without inhibitory inputs.
Deep Technical Breakdown

The phrasing "All Boolean functions cannot be implemented using only excitatory inputs" means: Not all Boolean functions can be implemented using only excitatory inputs. Let us examine the expressive power of an MP neuron with excitatory inputs alone:

y = 1    if ∑i=1n xi ≥ θ,    else 0

Notice that the mapping f(x) defined above is strictly monotonically non-decreasing: flipping any input variable from 0 to 1 can only increase (or leave unchanged) the sum ∑ xi, never decrease it. Therefore, an MP neuron with only excitatory inputs can only implement monotone positive Boolean functions.

Consider the elementary NOT gate: f(0) = 1, f(1) = 0.

  • Is the NOT function linearly separable? Yes! A threshold at 0.5 separates 0 from 1 in 1D.
  • Can it be implemented with an excitatory-only MP neuron? No! If f(0) = 1, then the threshold θ ≤ 0, which forces f(1) = 1 (contradiction). The NOT function strictly requires an inhibitory input.
  • Similarly, f(x1, x2) = x1 ∧ ¬x2 is linearly separable, yet it cannot be implemented without an inhibitory input.

Thus, inhibitory inputs are required not merely for non-linearly separable functions, but for any function exhibiting negative dependence, including simple linearly separable ones. Hence, the limitation holds for some Boolean functions regardless of linear separability (Option A).

Question 5 / 10 Hypercube Geometry
Suppose that we represent inputs x ∈ {0, 1}6 of a Boolean function as vertices of a hypercube in 6 dimensional space. Then the hyperplane defined by x1 + x2 + x3 + x4 + x5 + x6 = 0 only touches which of the following input?
A (0,0,0,0,1,0)
B (0,0,0,0,0,1)
C (0,1,1,0,0,1)
D (0,0,0,0,0,0)  [CORRECT ANSWER]
Deep Technical Breakdown

The vertex space of the 6-dimensional Boolean hypercube consists of points x = (x1, x2, x3, x4, x5, x6) where each coordinate xi ∈ {0, 1}.

Notice that for all i ∈ {1, 2, ..., 6}, we have the non-negativity constraint:

xi ≥ 0    ∀ i

We are given the hyperplane equation:

∑i=16 xi = 0

The sum of non-negative real numbers is zero if and only if every individual term in the summation is identically zero:

∑i=16 xi = 0  ⇔  x1 = x2 = x3 = x4 = x5 = x6 = 0

Testing the candidate options:

  • For (0,0,0,0,1,0): sum = 1 ≠ 0.
  • For (0,0,0,0,0,1): sum = 1 ≠ 0.
  • For (0,1,1,0,0,1): sum = 3 ≠ 0.
  • For (0,0,0,0,0,0): sum = 0 + 0 + 0 + 0 + 0 + 0 = 0.

The hyperplane is tangent to the hypercube at its bottom-most vertex, the origin (0,0,0,0,0,0) (Option D).

Question 6 / 10 Separability in 1D
We know that a Boolean function maps {0, 1}n → {0, 1}. How many linearly separable functions are there when n = 1?
A 0
B 1
C 2
D 4  [CORRECT ANSWER]
Deep Technical Breakdown

For any n, the total number of distinct Boolean functions is given by:

Ntotal = 2(2n)

For n = 1, the domain has 21 = 2 inputs: {0} and {1}. The total number of Boolean functions is:

2(21) = 22 = 4

Let us write out all 4 functions explicitly and construct their linear separating hyperplanes (which in 1D are simply single threshold points w·x + b = 0, or x = -θ):

  1. Constant 0: f(0) = 0, f(1) = 0 → Linear boundary: w = 0, b = -1 ⇒ 0·x - 1 < 0 for all x. (Linearly separable).
  2. Identity: f(0) = 0, f(1) = 1 → Linear boundary: 1·x - 0.5 = 0 ⇒ x > 0.5 gives 1, x < 0.5 gives 0. (Linearly separable).
  3. NOT / Inversion: f(0) = 1, f(1) = 0 → Linear boundary: -1·x + 0.5 = 0 ⇒ -x + 0.5 > 0 gives 1, < 0 gives 0. (Linearly separable).
  4. Constant 1: f(0) = 1, f(1) = 1 → Linear boundary: w = 0, b = 1 ⇒ 0·x + 1 > 0 for all x. (Linearly separable).

In 1-dimensional space, two distinct points (0 and 1) on a line can always be partitioned in all 22 = 4 possible configurations by a single separating point. Non-linearly separable functions only appear when n ≥ 2 (such as XOR). Therefore, all 4 functions are linearly separable (Option D).

Question 7 / 10 Hyperplane Geometry
We know from the lecture that the decision boundary learned by the perceptron is a line in R2. We also observed that it divides the entire space of R2 into two regions, suppose that the input vector x ∈ R5, then the perceptron decision boundary will divide the whole R5 space into how many regions?
A 2  [CORRECT ANSWER]
B 3
C 5
D 4
E It depends on whether the data points are linearly separable or not
Deep Technical Breakdown

A single perceptron defines its decision boundary as a single affine hyperplane in d-dimensional Euclidean space Rd:

H = { x ∈ Rd : wTx + b = 0 }

By fundamental topology and linear algebra, any (d - 1)-dimensional hyperplane embedded in Rd separates the entire continuous space Rd into exactly two open half-spaces:

H+ = { x ∈ Rd : wTx + b > 0 }    (Positive Region)
H- = { x ∈ Rd : wTx + b < 0 }    (Negative Region)

This topological property is strictly invariant to dimension:

  • In R1: A point (0-D hyperplane) divides the 1D line into 2 rays.
  • In R2: A line (1-D hyperplane) divides the 2D plane into 2 half-planes.
  • In R3: A plane (2-D hyperplane) divides the 3D space into 2 half-spaces.
  • In R5: A 4-dimensional hyperplane divides the 5D space into exactly 2 regions.

Hence, the answer is unconditionally 2 (Option A).

The perceptron learning algorithm performs a weight update only when an instance is misclassified. Let us test all 4 training samples against the initial weight vector w = [1, 1]T:

  1. Instance 1: x = [0, 0]T, True y = 0
    wTx = (1)(0) + (1)(0) = 0

Question 9 / 10 Non-Convergence of Bias-Free Perceptron
Consider the following table, where x1 and x2 are features and y is a label:
x1x2y
001
011
101
110
Assume that the elements in w are initialized to zero and perceptron learning algorithm is used to update the weights w. If the learning algorithm runs for long enough iterations, then:
A The algorithm converges (i.e., no further weight updates) after some iterations
B The algorithm never converges  [CORRECT ANSWER]
C The classification error becomes zero eventually
D The classification error remains greater than zero  [CORRECT ANSWER]
Deep Technical Breakdown & Proof of Infinite Cycle

This table defines the NAND operation. Crucially, notice the problem formulation:

  • Weights w ∈ R2 without an explicit bias term b (or origin-constrained decision boundary wTx = 0).
  • Rule: ŷ = 1 if wTx > 0, and ŷ = 0 if wTx ≤ 0.
  • Standard update rule for misclassified sample (x, y):
    If y = 1, ŷ = 0:    w ← w + x
    If y = 0, ŷ = 1:    w ← w - x

Fatal Obstacle at the Origin (0,0):

For the point x = [0, 0]T, the dot product is identically zero for any weight vector: wT[0, 0]T = 0. Under the decision rule, since 0 ≤ 0, the prediction is always ŷ = 0.

However, the true target label is y = 1! Therefore, [0, 0]T is permanently misclassified. Worse still, when an update is attempted on [0, 0]T:

w ← w + [0, 0]T = w    (Zero change!)

Explicit Step-by-Step Cycle Trace:

Start with w0 = [0, 0]T:

  • Sample (0,0), y=1: wTx = 0 ⇒ ŷ=0 (Error). w ← [0,0] + [0,0] = [0, 0]T.
  • Sample (0,1), y=1: wTx = 0 ⇒ ŷ=0 (Error). w ← [0,0] + [0,1] = [0, 1]T.
  • Sample (1,0), y=1: wTx = (0)(1) + (1)(0) = 0 ⇒ ŷ=0 (Error). w ← [0,1] + [1,0] = [1, 1]T.
  • Sample (1,1), y=0: wTx = (1)(1) + (1)(1) = 2 > 0 ⇒ ŷ=1 (Error!). w ← [1,1] - [1,1] = [0, 0]T.

The weights have returned exactly to [0, 0]T! The algorithm enters an infinite loop:

[0, 0]T → [0, 1]T → [1, 1]T → [0, 0]T → ...

Therefore, The algorithm never converges (Option B) and The classification error remains greater than zero (Option D).

Question 10 / 10 Hyperplane Geometry & Orthogonality
The statement that "In perceptron model, the weight vector w is always orthogonal to the linear decision boundary" is:
A True  [CORRECT ANSWER]
B False
Rigorous Mathematical Proof

Let the decision boundary of the perceptron be the set of all points x that satisfy:

S = { x ∈ Rd : wTx + b = 0 }

To prove that the vector w is orthogonal to this boundary, choose any two arbitrary distinct points xa and xb lying on the decision boundary S.

Because both points belong to S, both must satisfy the equation:

1)   wTxa + b = 0
2)   wTxb + b = 0

Now subtract equation (2) from equation (1):

(wTxa + b) - (wTxb + b) = 0
⇒ wTxa - wTxb = 0
⇒ wT(xa - xb) = 0

The difference vector v = xa - xb represents an arbitrary displacement vector lying entirely inside (parallel to) the decision boundary surface.

Because their inner product equals zero (wTv = 0), the weight vector w is strictly perpendicular (orthogonal / normal) to every tangent direction along the decision surface. Moreover, w points in the direction of the positive half-space (where wTx + b > 0 increases most rapidly).

Thus, the statement is unconditionally True (Option A).

Foundations & First Principles: Master Guide

1. The Evolution of the Artificial Neuron

Modern deep neural networks descend from mathematical abstractions of cortical wetware:

  • McCulloch-Pitts (1943): First computational model. Binary inputs, binary thresholding, unweighted excitatory inputs (+1) and veto inhibitory inputs (∞ negative weight). Unable to learn weights from data.
  • Rosenblatt Perceptron (1958): Introduced continuous real-valued weights w ∈ Rd and an automatic iterative learning rule driven by error correction.
  • Adaline / Sigmoid / ReLU: Transitioned from step functions to smooth differentiable activations, unlocking backpropagation and deep hierarchical representations.

2. Why the Bias Term b is Essential

A decision boundary without a bias has the equation wTx = 0. This restricts the separating hyperplane to pass strictly through the origin 0. As proven in Question 9:

  • Any point at the origin x = 0 yields wT0 = 0 ≤ 0 for any choice of weights.
  • If a dataset requires the origin to have label y = 1 (such as NAND, NOR, or inverted thresholds), a bias-free perceptron can never separate the data, leading to perpetual cyclic oscillation.
  • Introducing an adjustable scalar bias b allows the hyperplane to translate freely away from the origin:
    wTx + b = 0  ⇔  Distance to origin = |b| / ||w||

3. The Perceptron Convergence Theorem

Novikoff (1962) proved that if a dataset D is strictly linearly separable with margin γ > 0 (meaning there exists an optimal unit vector w* such that yi(w*Txi) ≥ γ for all i, with ||xi|| ≤ R), then the Perceptron learning algorithm is guaranteed to converge in at most:

k ≤ ( R / γ )2    updates

When the dataset is not linearly separable—or when the hypothesis class cannot represent the offset due to the absence of a bias term—the premise γ > 0 fails, and the algorithm oscillates indefinitely without converging.
